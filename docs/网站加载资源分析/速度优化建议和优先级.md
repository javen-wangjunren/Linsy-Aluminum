## 二、核心性能瓶颈

### 🔴 P0 - 最关键问题

#### 1. CSS 文件过多且全部渲染阻塞

**问题描述:**
- 共 47 个 CSS 文件全部为 `renderBlocking: true`（VeryHigh 优先级）
- 每个 Elementor 组件/widget 单独加载 CSS 文件
- 路径模式: `wp-content/plugins/elementor/assets/css/widget-*.min.css`
- 虽然使用了 WP Rocket 缓存插件 (`wp-content/cache/min/1/`)，但仍未有效合并

**涉及的插件及 CSS 数量:**
- Elementor / Elementor Pro — ~20 个 CSS 文件
- ElementsKit Lite — 2 个 CSS 文件 (其中 `widget-styles.css` 达 455KB)
- Mystickyelements Pro — 3 个 CSS 文件
- MetForm — 4 个 CSS 文件
- Bellows Accordion Menu — 3 个 CSS 文件
- TranslatePress — 1 个 CSS 文件
- Hello Elementor 主题 — 3 个 CSS 文件

**建议:**
- 在 Elementor 设置中启用 **"合并 CSS 文件"** 选项
- 使用 WP Rocket 的 **"优化 CSS 提交"** 功能合并内联
- 将首屏关键 CSS 内联到 `<head>` 中，非关键 CSS 异步加载
- 考虑用更少插件的替代方案

#### 2. 资源重复加载

**问题明细:**

| 重复资源 | 出现次数 | 浪费传输 |
|---------|---------|---------|
| `font-awesome/css/all.min.css` (不同 ver 参数: 1780502036 vs 1733482222) | 2 次 | ~30 KB |
| `www.gstatic.com/recaptcha/.../styles__ltr.css` (完全相同) | 2 次 | ~86 KB |
| `prod-cdn.webtune.ai/.../changes.json` (404 请求重复) | 2 次 | 浪费连接 |

**建议:**
- 排查哪两个插件分别加载了不同版本的 Font Awesome，统一版本
- 检查 reCAPTCHA 配置，确保只加载一次样式
- 修复 webtune.ai 插件配置，避免重复 404 请求

#### 3. Google Fonts 外部请求开销大

**问题描述:**
- 3 个 Google Fonts 请求，平均每个耗时 **965ms ~ 1076ms**
- 每次需要建立新的 SSL 连接（~680ms 握手时间）
- 请求字体: Inter (300/400/500)、Roboto (300/400/500)、Inter + Roboto Mono (全字重)

**建议:**
- **将 Google Fonts 自托管到本服务器**，消除外部 SSL 连接开销
- 如果使用 Google Fonts 的 CDN，添加 `<link rel="preconnect" href="https://fonts.googleapis.com">` 和 `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>`
- 精简字体字重，只加载实际使用的字重

### 🟠 P1 - 重要问题

#### 4. TTFB (服务器响应时间) 过长

**高 TTFB 请求:**

| 请求 | TTFB | 状态 |
|------|------|------|
| `elementskit-lite/widget-styles.css` | **989 ms** | ⚠️ MISS |
| `mystickyelements-front.min.css` | **989 ms** | ⚠️ MISS |
| `post-1093.css` (background-css) | **810 ms** | ⚠️ MISS |
| `intlTelInput.css` | **810 ms** | ⚠️ MISS |

**原因分析:**
- 部分 CSS 请求未命中 Cloudflare CDN 缓存（`cf-cache-status: MISS`）
- `background-css` 路径的请求需要 WP Rocket 动态生成，无法被 CDN 有效缓存
- 服务器后端处理时间（PHP + MySQL）过长

**建议:**
- 启用 WP Rocket 的 **"预加载缓存"** 功能，确保所有页面被 CDN 缓存
- 升级服务器配置（CPU/RAM）提升 PHP 处理能力
- 考虑使用全站静态化缓存方案

#### 5. 第三方脚本臃肿

**第三方加载分析:**

| 第三方服务 | 传输大小 | 主线程耗时 | 用途 |
|-----------|---------|-----------|------|
| **Google Tag Manager** | **1.3 MB** | **71 ms** | 数据分析 |
| **Google CDN (reCAPTCHA)** | **897 KB** | **69 ms** | 表单验证 |
| **Yandex Metrica** | **268 KB** | **19 ms** | 访问统计 |
| **Webtune.ai** | **28 KB** | 2 ms | SEO 优化 |
| **Cloudflare (rum/email-decode)** | **33 KB** | 2 ms | 安全/分析 |
| **Google Ads** | 少量 | - | 广告追踪 |
| **DoubleClick** | 少量 (含 1 个 400 错误) | - | 广告追踪 |

**建议:**
- GTM 使用 `defer` 或 `async` 延迟加载，不在首屏阻塞
- reCAPTCHA 改为仅在用户交互时（点击表单）才加载
- 评估 Yandex Metrica 的必要性，如果主要市场不在俄罗斯可移除
- 修复 webtune.ai 的 404 请求问题

#### 6. 缺少 Preconnect 预连接

**问题描述:**
- Performance Trace 显示 **没有配置任何 preconnect 标签**
- 最大关键路径延迟 641ms，部分原因是没有预连接到 Font Awesome 字体域

**建议:**
- 在 HTML `<head>` 中添加以下 preconnect:
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="preconnect" href="https://www.gstatic.com">
  <link rel="preconnect" href="https://www.googletagmanager.com">
  ```

### 🟡 P2 - 需优化问题

#### 7. 图片优化

**问题描述:**
- 大部分产品图片使用了 `data:image/svg+xml` 占位图（lazyload 占位）
- 正式图片以 WebP 格式加载，这一点很好
- 但占位 SVG 增加了 DOM 大小

**建议:**
- 使用低质量 blur-up 占位图替代纯 SVG 占位
- 为产品图片添加 `srcset` 响应式图片适配
- 确保所有图片设置了明确的 `width` 和 `height` 属性防止 CLS

#### 8. WP Rocket 配置优化

**问题描述:**
- 虽然使用了 WP Rocket，但 CSS 合并效果不理想（仍有 47 个独立 CSS）
- 部分 `background-css` 请求无法被 CDN 缓存

**建议:**
- 启用 **"合并 CSS 文件"** 和 **"移除未使用的 CSS"** 功能
- 生成和使用 **"关键 CSS"** 功能
- 启用 **"延迟加载 CSS"** 并将非关键 CSS 异步加载

#### 9. 控制台错误修复

**Lighthouse 发现:**
- `prod-cdn.webtune.ai/.../changes.json` — 404 错误
- 第三方 Cookie 警告

**建议:**
- 修复 webtune.ai 插件配置或考虑移除

#### 10. 无障碍 (Accessibility) 改进

| 问题 | 影响 |
|------|------|
| 颜色对比度不足 | 影响可读性 |
| 缺少 `<main>`  landmark | 影响屏幕阅读器导航 |
| Skip link 不可聚焦 | 影响键盘导航 |
| 部分链接缺少描述性文本 | 影响 SEO 和无障碍 |

## 四、技术细节补充

### 缓存现状

- Cloudflare CDN: ✅ 已启用，大部分请求 HIT
- WP Rocket: ✅ 已启用，CSS/JS 有 minify
- 浏览器缓存: ✅ 大部分资源 max-age=31536000 (1年)
- 问题: 部分 `background-css` 动态路径无法被有效缓存

### 网络协议

- HTTP/2: ✅ 已启用（多路复用）
- Brotli (br) / Gzip / Zstd 压缩: ✅ 已启用
- HTTP/3 (h3): ✅ Cloudflare 支持

### 关键渲染路径

```
HTML (37ms)
├── 47 个 CSS 文件 (每个 ~34-37ms) ← 渲染阻塞
├── 8 个 JS 文件 (每个 ~17-46ms) ← 渲染阻塞  
├── Font Awesome CSS (633ms)
│   └── fa-brands-400.woff2 (641ms) ← 最长的关键路径
├── Mystickyelements CSS (36ms)
│   └── fa-solid-900.woff (138ms)
└── 其他资源
```
